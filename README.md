# TP2 – Bases de JavaScript pour les applications mobile

## 📌 Description
Ce projet contient les exercices pratiques du TP2 sur les bases de JavaScript pour le développement d'applications mobiles.

## 🎯 Objectifs
- Comprendre les bases de JavaScript.
- Utiliser les variables et les types de données.
- Manipuler les conditions, les boucles et les fonctions.
- Pratiquer les tableaux et les objets.

- JavaScript
- Visual Studio Code
